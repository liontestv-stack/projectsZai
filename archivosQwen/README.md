# archivosQwen — regla de la carpeta

**Esta carpeta es SOLO para archivos ESENCIALES.**

Los tres grupos VITALES principales que viven aqui (y solo ellos):

| Grupo | Archivos |
|---|---|
| **CONFIG** (la receta) | `config.txt` |
| **ABRIR MODELO** | `abrir-qwen-apex.py`, `ABRIR-QWEN.bat`, `ABRIR-QWEN-CHARLA.bat` |
| **HABLAR MODELO** | `chatear-qwen.py`, `CHATEAR-QWEN.bat` |

**La regla:** si un archivo no sirve para abrir el modelo, hablar con el
modelo o configurar la receta, NO entra aqui. Todo lo demas (medidores,
campanas, tests, docs, evidencia) vive en `InformacionCritica\` y en
`investigacion\`. Las copias de seguridad viven en `backup\`.

**Y la fuente sigue siendo una:** si se edita la receta, se edita en
`InformacionCritica\configs\config.txt` y se re-copia aqui. Esta carpeta
es el kit de mano (una foto del dia), no la fuente de la verdad.

Mas detalle de uso (huellas, orden de busqueda del config, pasos en el
rig): ver `LEEME.txt`, el hermanito de este archivo.
